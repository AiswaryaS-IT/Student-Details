# Student Details Management System

## Overview
This project is a web-based Student Details Management System that allows users to add, retrieve, update, and delete student records. The system is built using HTML, CSS (Bootstrap), JavaScript, and Firebase for real-time database management.

## Features
- **Add Student Details**: Users can enter student information such as Roll Number, Name, Department, Semester, and CGPA.
- **Retrieve Student Details**: Fetches and displays student details from the database based on Roll Number.
- **Update Student Details**: Allows modification of existing student records.
- **Delete Student Details**: Removes student records from the database.
- **Display All Students**: Fetches and displays all student records in a table format.

## Technologies Used
- **Frontend**:
  - HTML5
  - CSS (Bootstrap 5.0.2)
  - JavaScript
- **Backend**:
  - Firebase Realtime Database
